HSIP Proof Check

Drop in an HSIP proof file or evidence pack and see whether it is genuine or has been altered. The check runs inside this page, on your computer. Nothing is uploaded.

Create a permission

Say what an agent may do and sign it with your own key. The key is made and kept in this page, on your computer. Nothing is sent anywhere.

Check records against a permission

Paste a signed permission (made with hsip-proof mandate-sign) and the proofs or evidence pack. The page lists every record that falls outside what was allowed. Same offline check, same rules.

Don't just trust this page.
  • It makes no network requests after loading. Turn your wifi off and it still works. Its security policy blocks it from contacting any other site.
  • It runs the same open-source verifier as the hsip-proof command-line tool (source: crates/hsip-proof in the HSIP repository). For a result you can rely on in a dispute, run that tool on your own machine.
  • This page is plain static files. Anyone can host their own copy.
  • A genuine result means the record is unaltered since it was signed. It does not mean the decision it describes was right.
