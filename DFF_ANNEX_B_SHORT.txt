4. What This Evidence Shows

Courts can determine from this artifact:

Consent Status:
- Consent was granted on March 14, 2026 at 10:42:18 UTC
- Purpose: marketing communications
- Duration: 730 days (expires March 14, 2028)
- Legal basis: GDPR Article 6(1)(a) explicit consent

Cryptographic Verification:
- Signature algorithm: Ed25519 (industry standard)
- Signature is valid and verified
- Public key available at example-company.com for independent verification

Timeline Evidence:
- Consent screen displayed: 10:41:45
- Consent button pressed: 10:42:17
- Time to decision: 32 seconds
- Timestamp accuracy: synchronized with NIST atomic clock

Technical Integrity:
- Database record created at consent time
- Never modified after creation (write-once constraint)
- Independently verifiable by any qualified expert


5. Independent Verification

Any court-appointed expert can verify this evidence using:

Required Information:
- This audit log entry (JSON format)
- Company's public key (published at their domain)
- Standard cryptographic libraries (NaCl/libsodium, open-source)

Verification Process:
1. Retrieve public key from example-company.com
2. Extract signature from audit log
3. Verify signature using Ed25519 algorithm (RFC 8032)
4. Confirm signature is valid = evidence is authentic

No proprietary tools or vendor cooperation required.
