Who is HSIP for?

Getting started

Up and running in 3 steps

Especially for Windows and Mac users, no command line required.

🪟 Windows

1

Download the .exe

One file. Click the Download button above and save the .exe anywhere, your Desktop is fine.

2

Double-click it

HSIP installs itself, creates a Desktop shortcut, and starts automatically. No installation wizard, no "next next finish."

3

Your browser opens automatically

HSIP opens right in your browser at localhost:7474. Everything is right there, no separate app, no learning curve. Next time: use the HSIP shortcut on your Desktop to start it again. If Windows shows a blue "Windows protected your PC" screen, click More info → Run anyway.

🍎 Mac

1

Download the binary

Pick Apple Silicon (M1/M2/M3/M4) or Intel depending on your Mac. Not sure? Click the Apple menu → About This Mac.

2

Run once in Terminal

Open Terminal, type chmod +x ~/Downloads/hsip-macos-arm64 && ~/Downloads/hsip-macos-arm64 and press Enter.

3

Your browser opens

HSIP opens in your browser automatically. Keep that Terminal window open (or minimized) to keep HSIP running.

🐧 Linux / Mac Terminal one-liner

curl -sSf https://raw.githubusercontent.com/rewired89/HSIP-1PHASE/main/install.sh | sh

Two things to check:

1. Windows SmartScreen may have blocked it. When you double-clicked the file, did Windows show a blue screen saying "Windows protected your PC"? If you clicked "Don't run", HSIP never started. Download it again, double-click, and this time click More info → Run anyway. HSIP is open source and safe — SmartScreen warns about any unsigned exe from the internet.

2. HSIP is simply not running. It needs to be running for localhost:7474 to load. Find the HSIP shortcut on your Desktop and double-click it to start. If the shortcut isn't there yet, run hsip-windows-x64.exe directly (clicking "Run anyway" on the SmartScreen prompt) and it will create the shortcut automatically.
